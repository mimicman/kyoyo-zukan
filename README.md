# 教養の図解（kyoyo-zukan）

教養を **1テーマ＝1枚の図解カード** で学ぶ自分用のページ。図と画像を主役にし、図の下の要点・例で理解し、もっと知りたいときは折りたたみの解説を読む。22分野（考える・歴史・社会・自然と科学・文化と芸術）。

- **公開URL**: https://mimicman.github.io/kyoyo-zukan/
- 検索エンジンには載せない（`noindex` と `robots.txt`）。URLを知っていれば誰でも見られるので、個人情報は書かない
- ビルドは不要。`main` に push すると、1〜2分で公開URLに反映される

## 画面

| URL | 画面 |
|---|---|
| `#/` | ホーム（今日の1枚・年表と人物辞典への入口・5つのまとまりごとの分野） |
| `#/<分野>` | 分野の目次。章ごとに、まとめカードと章のカード（既読に印） |
| `#/<分野>/<カード>` | カード。左右スワイプ・← →キーで前後（章をまたいで続く）、Escで目次へ。下に「つながりマップ」 |
| `#/timeline` | 年表。`years` のあるカードと人物を、分野をまたいで世紀ごとに並べる |
| `#/people` / `#/people/<人物>` | 人物辞典の一覧と人物ページ。カードの文中の人名はタップでミニ紹介 |

| パス | 中身 |

| `data/fields/<分野>.json` | その分野の章（`chapters`）とカード（`cards`）。**文字はすべてここに書く** |

## カードを1枚足す

1. `figures/<分野>/<id>.svg` に図を描く（下の「図の決まり」）
2. `data/fields/<分野>.json` の `cards` に追記する。並び順がそのまま番号になる
   ```json
   {
     "id": "supply-demand", "title": "需要と供給", "era": "18世紀〜",
     "line": "買いたい量と売りたい量が釣り合う所で、価格が決まる",
     "image": { "id": "adam-smith", "pos": "50% 25%" },
     "points": ["右下がりの線が需要…", "右上がりの線が供給…", "高すぎると売れ残り…"],
     "example": "品薄で値上がりした商品も…",
     "why": "ニュースの「値上がり」「値崩れ」の理由を…",
     "keywords": [{ "word": "均衡価格", "note": "需要と供給がちょうど一致するときの価格" }],
     "more": "需要と供給の考え方は…（150〜400字）",
     "links": ["economics/inflation"]
   }
   ```
   `image` は任意（`pos` は帯に切り抜くときの中心）。`links` は関連カード（他分野も可）
3. 画像を使うなら取得する（パブリックドメイン/CC0 以外は保存されない）
   ```
   python3 tools/fetch_commons.py --check "File:ファイル名.jpg"
   python3 tools/fetch_commons.py <分野>-<名前> "File:ファイル名.jpg" "表示名（作者）"   # 800pxに自動で縮小
   ```
4. `python3 tools/validate.py`（分野を絞るなら `--fields 分野,分野`）で問題0件にする
5. `<Playwright入りのpython> tools/check_layout.py <分野>/<id>` で表示を確認し、`tmp/screenshots/` の画像で図の文字の重なりを見る
6. コミットして push

分野を増やすときは、`data/index.json` の `fields` に追加して `data/fields/<分野>.json` を作り、`assets/style.css` の分野色（`--c-<分野>` をライト・ダーク両方と `[data-field]`）と、`index.html` の矢印 `a-<分野>` を足す。

## 章とまとめカード

- 分野は3〜5章に分ける（`chapters: [{id, name, desc}]`）。各カードに `chapter`
- 各章の先頭に **まとめカード**（`"kind": "summary"`、id は `<章id>-summary`）を1枚。図は章のカードどうしの関係（流れ・比較・地図）を一目で示す。画面では「この章のカード」の一覧が自動で付く
- `years: [開始年, 終了年]`（整数、紀元前は負）を付けたカードは年表に載る。法則や概念など時代のないものは付けない
- `links` は最大4件。分野をまたいで「前提」「次に読む」を張る。逆向き（このカードへ来るカード）は自動で表示される

## 人物辞典

```json
{ "id": "newton-isaac", "name": "アイザック・ニュートン", "aliases": ["ニュートン"],
  "years": [1643, 1727], "region": "世界", "line": "何をした人か（30字）",
  "image": { "id": "science-newton", "pos": "50% 20%" },
  "events": [{ "year": 1687, "text": "30字以内" }], "did": ["60字×3"], "legacy": "60字",
  "more": "150〜400字", "figure": "（任意）figures/people/<id>.svg", "cards": ["science/gravity"] }
```
- `name` と `aliases`（2文字以上）がカードの文中に出ると、自動で下線リンクになる（1枚のカードで同じ人は最初の1回だけ）
- 人物はその人が主に属する分野のファイルに1回だけ書く（重複は validate が検出）

## 文字の決まり（validate.py が検査）

| 要素 | 上限 |
|---|---|
| 見出し `title` | 15字 |
| ひとこと `line`（図が言いたいことを1行で） | 30字 |
| 要点 `points`（図の読み方・仕組みを順に） | ちょうど3つ、各60字 |
| 例 `example`（身近な例・具体例） | 60字 |
| なぜ大事 `why` | 50字 |
| もっと詳しく `more`（背景・人物・誤解されやすい点、文章で） | 150〜400字 |
| キーワード | 3つまで、説明 `note` は40字 |
| つながり `links` | 4件まで |

- カード1枚だけで初めての人がわかること。専門用語は言い換えるか、キーワードで説明する
- 要点は「図のどこを見るか→何が起きるか→だからどうなるか」の順で、図の言葉と合わせる
- 医学・健康は仕組みの説明にとどめ、治療や健康法の助言は書かない
- 年号は確実なものだけ書き、自信のないものは世紀単位にする。名言の引用や、すぐ古くなる統計値は書かない
- 政治・宗教など評価が分かれる話題は、特定の立場を取らない

## 図の決まり

- `viewBox="0 0 360 280"`（縦は必要なら伸ばしてよい）。図がカードの主役
- 色は直接書かず、クラスだけで指定する（ダークモードに自動で対応するため）
  - 塗り: `.ink`（文字色）`.soft`（薄い文字色）`.fl`（分野色）`.on`（分野色の上の文字）`.tint`（分野色の淡い面）`.paper` `.bgc`
  - 線: `.st` `.st-soft` `.st-f` `.st-line`、点線は `.dash`
  - 文字: `.t-xl` `.t-l` `.t-m` `.t-s` `.t-xs`、中央揃え `.mid`、右揃え `.end`、線と重なる文字は `.halo`（背景色のふち取り）
- `id` 属性は使わない（ページに埋め込むと衝突する）。矢印は `index.html` の共通のものを使う
- 一覧のサムネイルでは図の文字は消える。文字がなくても形で区別できる図にする
